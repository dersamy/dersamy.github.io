// The brief

A lower-cost robotics toy needed stripped-down hardware: no onboard programmability, controlled through a companion mobile app.

// What I built

I designed a simplified ESP32/BLE PCB driving two motors, controlled via a companion mobile app instead of onboard code. It is deliberately minimal, with headers left unpopulated so it can be extended toward the full controller later, for example with sensors or programming add-ons.

// Result

The board ships as a commercial product. Its open expansion header is what the USB-UART programming module plugs into.
