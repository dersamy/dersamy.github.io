Edge AI Human Detection System for Smart Queue Management

Master's graduation project: cloud-independent human detection on a microcontroller.

STACK
ESP32-S3 · OV2640 · TensorFlow Lite Micro
STATUS
Completed, 2023
TYPE
Master's thesis (USTHB)

// The brief

Occupancy and queue tracking usually relies on a server or cloud service. The goal was fully on-device human detection on a microcontroller, aimed at real-time queue management.

// What I built

A custom ESP32-S3 + OV2640 PCB (EasyEDA, JLCPCB) with a 3D-printed enclosure. I optimized a TensorFlow classification model for microcontroller deployment via int8 quantization, then ran it through TensorFlow Lite for Microcontrollers on the ESP32-S3 for fully on-device inference, with no host or cloud in the loop.

// Result

Real-time inference at 5 FPS on 96×96 grayscale frames, running standalone on a microcontroller. The core constraint was fitting a usable classification model into the ESP32-S3's memory and compute budget.
