ESP32-Based STEM Robotics Controller & Custom Firmware

Full-stack hardware and firmware for a commercial robotics kit.

TYPE

// The brief

A commercial STEM robotics kit needed a controller board that could drive motors and read a set of on-board sensors, while staying friendly to young learners programming it in Scratch.

// What I built

I designed an ESP32 PCB powered by 6×AAA batteries to drive motors and on-board sensors (line, color, compass, ultrasonic). On the firmware side: a custom MicroPython image with C driver bindings per peripheral, plus a BLE bridge layer exposing the same firmware to Scratch.

// Result

The controller ships as part of a commercial product. Brownout-free operation on 6×AAA with motors, sensors and BLE all active took a few board revisions to nail down.
