16-bit CPU From Scratch

Learning CPU design from first principles, one instruction at a time, in Vivado and VHDL.

STACK
VHDL · Xilinx Zynq Z7-10 · Python
STATUS
Working, simulated + on FPGA
TYPE
Educational / foundational
FPGA · VHDL16cpu-16bit

// The brief

Before starting QoSoC, I wanted to understand CPU design from the ground up rather than treating a core as a black box.

// What I built

A basic 16-bit CPU built from scratch in VHDL (datapath, control unit and a small instruction set), simulated and validated on the Xilinx Zynq Z7-10 FPGA. I also wrote a Python assembler that turns assembly into a memory map.

// Result

A working CPU, simulated and running on FPGA. It is deliberately simple, but everything in it I built and debugged myself.
