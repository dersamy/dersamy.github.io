PCB — STM32 4-Wheeled Robot Motor Control Board

A compact 2-layer board driving four independent motors with hall-encoder feedback.

STACK
KiCad · STM32F103 · Embedded C
STATUS
Built & running
TYPE
Motor driver board

// Problem

A 4-wheeled robot needs independent, closed-loop control of each wheel — open-loop PWM alone isn't enough once accurate speed or odometry matters, so the board needed real encoder feedback per motor, not just drive signals.

// Approach

The board was laid out as a compact 2-layer PCB around an STM32F103, with hall-encoder inputs feeding closed-loop control for all four motors. Firmware in Embedded C handled the control loop and encoder processing, and exposed the board over UART, CAN, and USB so it could be driven either standalone or as part of a larger robot control stack.
