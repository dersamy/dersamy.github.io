PCB: STM32 4-Wheeled Robot Motor Control Board

A compact 2-layer board driving four independent motors with hall-encoder feedback.

STACK
KiCad · STM32F103 · Embedded C
STATUS
Built & running
TYPE
Motor driver board
PCB · FirmwareMCpcb-stm-moteur

// The brief

A 4-wheeled robot needs independent, closed-loop control of each wheel. Open-loop PWM alone is not enough once accurate speed or odometry matters, so the board needed real encoder feedback per motor, not just drive signals.

// What I built

A compact 2-layer PCB around an STM32F103, with hall-encoder inputs feeding closed-loop control for all four motors. Firmware in Embedded C handles the control loop and encoder processing, and exposes the board over UART, CAN and USB, with I²C for sensor expansion, so it can be driven standalone or as part of a larger robot control stack.

// Result

A built and running motor control node that works standalone or inside a larger robot system.
