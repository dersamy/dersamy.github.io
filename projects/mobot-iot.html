// The brief

A commercial IoT education kit needed one board that could host a wide set of sensors and outputs, powered from USB or batteries, and connected over Wi-Fi and BLE.

// What I built

I designed an ESP32-S3 PCB, powered by USB or 6×AAA batteries, driving six sensor types (gas, LDR, potentiometer, DHT, PIR, RFID) and four outputs (OLED, 7-segment, servo, 5V fan). The firmware is built on the same custom MicroPython image and driver bindings as the robotics controller. The main design problem was fitting six sensor types and four outputs onto one MCU's GPIO/ADC budget.

// Result

The board ships as part of a commercial product, sharing its driver layer with the robotics controller so both kits are maintained from one firmware base.
