Soil Quality Measurement System

A remote soil-monitoring board built around an Atmega328P, GSM backhaul, and an RS485 soil sensor.

STACK
KiCad · Atmega328P · SIM800L GSM · RS485
STATUS
Built & running
TYPE
Remote IoT sensor board

// Problem

Soil monitoring in the field means no easy access to Wi-Fi or wired networking, and often a sensor bus that has to run over a longer cable run than typical hobby wiring — both of which push the design toward cellular backhaul and a more robust physical layer than plain I²C or UART.

// Approach

The board pairs an Atmega328P with a SIM800L GSM module for connectivity, and reads the actual soil sensor over RS485, which tolerates longer runs and noisier environments far better than single-ended serial. A meaningful part of the effort went into power delivery and signal integrity, keeping communication stable over distance despite running on a small, power-constrained board.
